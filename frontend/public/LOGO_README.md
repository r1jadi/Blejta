# Logo Setup

## Adding the Blejta Logo

1. **Place your logo file** in this directory (`frontend/public/`) with the name `logo.png`

2. **Recommended specifications:**
   - Format: PNG (with transparency) or SVG
   - Size: At least 100x100px (will be displayed at 50x50px)
   - The logo should be circular or square with a beige/cream background
   - Text: "Blejta" with ".ks" below/next to it

3. **Alternative formats:**
   - If you have `logo.jpg` or `logo.svg`, update `frontend/app/layout.tsx` to use the correct extension

4. **Current logo description:**
   - Circular logo with beige/cream background
   - "Blejta" text in dark brown/charcoal
   - ".ks" text in smaller font
   - Clean, minimalist design

The logo will automatically appear in the header once the file is added.
